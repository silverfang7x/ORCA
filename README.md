# ORCA — Multi-Agent AI System

ORCA is a conversational multi-agent AI platform designed for fishermen and coastal authorities for Smart India Hackathon 2026 (SIH26176, sponsored by ISRO/Dept of Space). It orchestrates specialized AI agents to provide explainable safety advisories, real-time weather and ocean insights, and hazard alerts in local languages.

For full architectural details, team ownership boundaries, and project specifications, see [`CONTEXT.md`](./CONTEXT.md).

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm (v9 or higher recommended)

### Quick Setup

```bash
# Clone the repository
git clone https://github.com/silverfang7x/ORCA.git
cd ORCA

# Install workspace dependencies at root
npm install
```

> **Note**: Frontend and Backend application packages will be scaffolded in upcoming steps.
